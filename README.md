# BetterScratch website

A standalone static website. Edit `dist/index.html` and `dist/styles.css`; assets are in `dist/assets/`. No dependency installation or build is needed.

Preview from this folder with `python3 -m http.server 4173 --directory dist`, then open http://127.0.0.1:4173.

The three **Add to Chrome** links currently open https://chromewebstore.google.com/ as requested. Replace the `href` on each `.install-link` and update the listing-coming-soon copy when a listing is available.

The project screenshot is user supplied. Feature descriptions are based on the extension source and repository documentation. The website has no tracking, external fonts, JavaScript, animations, or third-party dependencies.
